DP AUDIT AUTOMATION TOOLKIT
============================

How to use:
1. Extract this ZIP file.
2. Open "index.html" in Chrome or Microsoft Edge.
3. Click any of the three tool cards.
4. To make this accessible to recruiters from your CV, upload this entire folder to a static web-hosting service.

Files:
- index.html
- COD_Analyzer_v10.html
- DP_Audit_Report_Builder.html
- DP_KYC_AOF_Audit_Tool.html

The three original HTML tools have been preserved without changing their source code.
